前言

跟著老師的步驟，從一開始完全沒有碰過程式設計，到現在能夠依照老師的指示，做出一個能看的作品，讓我十分感動。

內文

先是從 GitHub 的註冊開始，接著學習如何將專案透過 git clone 下載到近端進行操作，在本機完成修改與練習後，再使用 git push 將成果上傳回 GitHub。透過這樣的流程，我逐漸理解版本控制的概念，也更清楚程式從寫到整理與管理的實際運作方式。
同時，在老師的教學下建立個人網頁，並開始寫 Python 程式語言，從一開始寫一些相對簡單的程式，到後來能夠完成多個老師的作業，每一步都是非常辛苦，也讓我對程式的邏輯與流程有更深的理解。

結尾

從完全沒有基礎，到現在能夠實際完成作品，這段學習經驗讓我獲益良多，不只是學到程式語言本身，也培養了對工具使用與問題解決的能力，讓我對程式設計產生更多的信心與成就感。
